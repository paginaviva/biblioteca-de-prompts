Biblioteca de Prompts

Gestiona, organiza y busca tus instrucciones para inteligencia artificial

Aplicación web de código abierto para crear, editar y organizar mensajes (prompts) para diferentes modelos de IA, con categorías, etiquetas, búsqueda de texto completo y copiado con un clic.

Ver en GitHub Manual de usuario

Tenedor (fork) de YellowBerry007/prompt-database, con crédito a su creador Berry @ Yellowgrape.

Características

Todo lo necesario para mantener tu biblioteca de instrucciones bajo control

Creación y edición

Crea, edita y elimina instrucciones con un formulario completo.

Categorías jerárquicas

Organiza con categorías de dos niveles y etiquetas.

Búsqueda de texto completo

Busca en título, descripción y cuerpo de cada instrucción.

Filtros combinados

Filtra por categoría, etiqueta, plataforma, estado y favoritos.

Copiado con un clic

Copia cualquier instrucción al portapapeles con un solo clic.

Seguimiento de uso

Contador de usos y fecha del último uso de cada instrucción.

Favoritos y duplicado

Marca como favoritas y duplica instrucciones fácilmente.

Exportación e importación

Exporta e importa tu biblioteca en formato JSON.

Multiusuario

Autenticación de usuarios y aislamiento de instrucciones por usuario.

Multilingüe

Interfaz en español e inglés, con selector de idioma.

Requisitos

Para instalar y ejecutar la aplicación

  • Node.js versión 20 o superior
  • npm, yarn o pnpm como gestor de paquetes
  • Base de datos PostgreSQL (por ejemplo, Neon)
  • Cuenta de Vercel para el despliegue
