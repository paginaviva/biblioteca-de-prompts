# Lista de capturas de pantalla

Ubicación de destino: carpeta `screenshots/` en la raíz del repositorio.
Sección del README donde se mostrarán: "Capturas de pantalla" (después de la sección de características).

| Número | Nombre de archivo | Contenido esperado (descripción ampliada) | Ubicación en el README |
|---|---|---|---|

Debe apreciarse la organización en tarjetas o filas, el contador de resultados y el botón de borrado del campo de búsqueda. ## Formato recomendado

- Formato PNG.
- Capturas de pantalla completas (ventana completa o vista completa del navegador).
- Resolución suficiente para lectura cómoda en el README (ancho mínimo recomendado: 1200 píxeles).
- Sin datos personales reales: si aparecen mensajes de ejemplo, deben ser ficticios.
- Para la vista de administración, no capturar datos reales de usuarios.
